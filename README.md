# Student Money Copilot

## Idea

Student Money Copilot is a private local-AI financial assistant for
students. It helps users understand how much they can safely spend,
considers upcoming expenses, and can eventually propose RGB payments
that the user explicitly approves.

## Stack

- Python
- Streamlit
- QVAC local AI
- RGB / KaleidoSwap tooling
- Docker

## Work completed before the hackathon

The following was completed before the official hackathon start:

- Basic Streamlit UI
- Sample student transaction and expense data
- Python budgeting logic
- Safe-to-spend calculation
- Purchase affordability checker
- Local QVAC installation and working inference
- QVAC integrated into the Streamlit app for financial explanations
- Free-form Money Copilot prototype
- Kaleido RGB node setup
- Test Bitcoin wallet funded on the test network
- RGB-capable UTXOs created
- Test RGB NIA asset "Student Dollar" (STUSD) issued

## Not completed before the hackathon

- RGB payment integrated into the application
- Working wallet-to-wallet STUSD payment flow
- QVAC-triggered payment proposal
- RGB balance displayed in the application
- Final UX/UI
- Final end-to-end demo

Those features will be developed during the hackathon.
